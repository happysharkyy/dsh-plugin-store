三条命令，把插件装进你的 DSH

  1. 1
    挑插件，复制命令

    卡片右下角「安装命令」直接复制，命令里已经带好内网包地址。

  2. 2
    在安装了 DSH 的机器上执行

    命令走 dsh plugin --profile web add，安装包已内置全部运行时依赖。

  3. 3
    重启 DSH 生效

    插件写入 profile 后，下次启动 dsh web 即以新配置组合加载。

安装命令示例Shell / PowerShell
dsh plugin --profile web add <商店地址>/packages/<包文件>.tgz
